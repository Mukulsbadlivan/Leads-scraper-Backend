# apps/worker

This directory is the designated home for the BullMQ worker process in the future Turborepo monorepo.

**Current location**: `d:\Job Portal Scraper\src\workers\scrapeWorker.ts`
**Start command**: `npm run worker` (from `d:\Job Portal Scraper`)

## When migrating to Turborepo:
Move `src/workers/` here and update the workspace configuration in `turbo.json`.
