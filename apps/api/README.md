# apps/api

This directory is the designated home for the Express API server in the future Turborepo monorepo.

**Current location**: `d:\Job Portal Scraper\src\api\server.ts`
**Start command**: `npm run api` (from `d:\Job Portal Scraper`)

## When migrating to Turborepo:
Move `src/api/` here and update the workspace configuration in `turbo.json`.
